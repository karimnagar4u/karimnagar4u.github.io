# Events & Rent/Lease Hub

A modern, responsive directory for local events and commercial/residential rental spaces with Jekyll Markdown generator support.

## 🚀 Deploying to `<your-username>.github.io`

### 1. Upload files to your GitHub repository
1. Go to your repository: `https://github.com/<your-username>/<your-username>.github.io`
2. Click **Add file** -> **Upload files** (or push via Git).
3. Drag and drop all the extracted files and folders (including `.github/workflows/deploy.yml`).
4. Click **Commit changes**.

### 2. Enable GitHub Pages
1. In your GitHub repository, click on **Settings** (top tab).
2. Click **Pages** in the left sidebar menu (under "Code and automation").
3. Under **Build and deployment** -> **Source**, select **GitHub Actions**.
4. GitHub will automatically trigger the deployment workflow located in `.github/workflows/deploy.yml`.

### 3. View your live website
- Go to the **Actions** tab in your repository to watch the build progress.
- Once completed with a green checkmark, your site will be live at `https://<your-username>.github.io`!
